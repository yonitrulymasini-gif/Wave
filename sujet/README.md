# TP 1 - Intégrer WAVE

## Contexte

WAVE est une plateforme fictive de découverte de concerts destinée aux 18-25 ans. Une maquette desktop et une maquette mobile ont été validées. Vous devez les intégrer en HTML et CSS, sans JavaScript et sans framework.

## Durée conseillée

3 heures.

## Livrables attendus

- `index.html` complété ;
- `style.css` complété ;
- aucune modification des fichiers placés dans `assets/`.

## Événements à présenter

| Date | Artiste ou événement | Style | Lieu et horaire |
|---|---|---|---|
| 19 septembre | Lina K | Électro | Le Flow, 20:30 |
| 22 septembre | Noa V | Rap alternatif | L'Aéronef, 21:00 |
| 27 septembre | North Waves | Open air, 6 artistes | Gare Saint-Sauveur, dès 18:00 |

## Contraintes techniques

1. Utiliser les balises sémantiques adaptées, dont `header`, `nav`, `main`, `section`, `article`, `figure`, `time` et `footer`.
2. Conserver un seul `h1` et une hiérarchie de titres cohérente.
3. Utiliser Flexbox et Grid dans des zones pertinentes.
4. Ne pas construire la mise en page principale avec `position: absolute`.
5. Ne placer aucun style dans le HTML et n'utiliser aucun framework.
6. Limiter le contenu principal à environ `1180px`.
7. Prévoir des états `:hover` et `:focus-visible` identifiables.
8. Adapter réellement la composition entre les versions desktop et mobile.
9. Ne provoquer aucun défilement horizontal à `390px`.
10. Rédiger des textes alternatifs pertinents pour les photographies.

## Vérification finale

- Désactivez la feuille CSS : le contenu doit conserver un ordre logique.
- Naviguez uniquement avec la touche Tab : chaque lien doit être repérable.
- Testez les largeurs `1440px`, `900px`, `680px` et `390px`.
- Validez le fichier HTML avec le validateur du W3C.
- Préparez-vous à expliquer chaque règle CSS importante.

Une modification courte sera annoncée en fin de TP afin de vérifier que votre structure peut évoluer sans être reconstruite.
